# 07. 다국어 · 국가 표시 자동 폴백

## 문제

AI 페르소나 등 특정 계정은 국가를 "고정" 하고 싶지 않은 경우가 있습니다 (viewer 마다
자연스럽게 보이길 원함). 그렇다고 국가 필드를 비워두면 표시할 때마다 예외 처리가
필요해지고, 앱이 지원하지 않는 언어권 국가가 뜨면 어색합니다.

## 해결

- 국가 코드에 `WORLD` 라는 **sentinel 값**을 둡니다. 실제 국가가 아니라 "표시 시점에
  viewer 에 맞는 국가로 대체하라" 는 의미로 사용합니다.
- 표시 시점에 sentinel 을 만나면:
  1. viewer 의 국가 코드가 있고, 그 국가의 주 언어가 앱이 지원하는 언어(en/ko) 안에
     있으면 → 그 국가를 그대로 사용.
  2. 아니면 → 현재 활성 앱 로케일의 대표 국가로 대체 (en → US, ko → KR).
- 언어 지원 여부 판정은 exhaustive switch 로 작성해, 지원 언어를 추가할 때 컴파일러가
  누락된 분기를 강제로 드러내게 했습니다.
